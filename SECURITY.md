# Política de segurança

Encontrou uma vulnerabilidade no Banco ENEM? Não abra issue pública. Use a aba **Security › Report a vulnerability** deste repositório no GitHub, que cria um relato privado.

O site é estático e não guarda dados de quem usa. Detalhes do modelo de ameaça em [docs/security.md](docs/security.md).
